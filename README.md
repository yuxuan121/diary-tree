# diary-tree · 日记树（日常伴随技能）

> 认知陪伴工具，非专业医疗建议。

## 这是什么
常驻式日记技能：捕捉「做到的事」、保守感知情绪、低频真实鼓励、结构化存储，帮用户积累"我一直在进步"的认知。

## 两种模式（首次启用必选）
| 模式 | 说明 |
|---|---|
| **A｜全时记录** | 只要说话就进入记录模式，日常对话自动捕捉 |
| **B｜触发记录** | 说触发词（"记一篇日记树""记日记""引导我记日记"）才记录 |

选择写入 `config.md`；随时说"切换记录模式"可更改。

## 安装
1. 将 `diary-tree` 文件夹放入 Operit 的 skills 目录（`/sdcard/Download/Operit/skills/`）
2. 首次调用技能时选择记录模式
3. 开始使用

## 文件结构
```
diary-tree/
├── SKILL.md        # 技能主体（含模式选择逻辑）
├── config.md       # 当前模式（首次启用后生成）
├── <YYYY-MM-DD>.md # 每日记录
├── index.md        # 索引：日期 | 主题 | 情绪
└── highlights.md   # 美好素材库（鼓励引用来源）
```

## 设计原则
- 鼓励只引用真实经历，不编造、不夸大
- 不打断工作流：事务性对话只静默记录
- 不评判、不诊断、不开药、不替代心理治疗
- 遇严重情绪危机 → 建议专业支持
